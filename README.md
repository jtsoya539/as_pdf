# as_pdf
Generate a PDF document from an Oracle database.

AS_PDF is a native PL/SQL package to generate PDF documents.

It was written by [Anton Scheffer](https://github.com/antonscheffer), former Oracle Consultant at AMIS and now member of the Oracle APEX team.

This is an updated version of the original version 3, still available at the [AMIS blog](https://technology.amis.nl/), with some additions by [Valerio Rossetti](https://github.com/Valerio-Rossetti), [Andreas Weiden](http://andreas-weiden-orcl.over-blog.de/), [Lee Lindley](https://github.com/lee-lindley) and me, [Javier Meza](https://github.com/jtsoya539).

For the new and updated version 4 by Anton, please refer to: https://github.com/antonscheffer/as_pdf
